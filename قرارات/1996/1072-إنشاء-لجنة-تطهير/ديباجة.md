قرار أمين اللجنة الشعبية العامة للعدل والأمن العام

رقم ( 1072 ) لسنة 1425 ميلادية

بشأن إنشاء لجنة تطهير

أمين اللجنة الشعبية العامة للعدل والأمن العام،

بعد الإطلاع على القانون رقم ( 10 ) لسنة 1423 ميلادية بشأن التطهير ولائحته التنفيذية.

وعلى القرار رقم ( 100 ) لسنة 1423 ميلادية بشأن تشكيل لجان تطهير وإجراءات عملها وتحديد مقارها ودوائر اختصاصها.

قــــــــــــــــرر

مادة (

1

)

تنشأ لجنة تطهير بمنطقة أبو نجيم وتتكون من :

1- الأخ بالقاسم مختار بشير رئيسا

2- الأخ سعيد سلامة البركي عضوا

3- الأخ أحمد جمعة سعود عضوا

4- الأخ مفتاح الواعر عضوا

5- الأخ علي محمد أبوحليقة عضوا

مادة (

2

)

تتولى اللجنة المشار إليها في المادة السابقة في سبيل تنفيذ مهامها ممارسة كافة الصلاحيات الواردة في القانون رقم ( 10 ) لسنة 1423 ميلادية بشأن التطهير ولائحته التنفيذية، وتمارس أعمالها وفقا لأحكامها وأحكام القرار رقم ( 100 ) لسنة 1423 ميلادية المشار إليه.

مادة (

3

)

يعمل بهذا القرار من تاريخ صدوره، وينشر في الجريدة الرسمية.
