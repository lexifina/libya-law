قرار وزير الداخلية المفوض

رقم (

156

) لسنة 2016م

بشأن إنشاء غرفة أمنية مشتركة لتأمين وحماية طرابلس الكبرى

وزير الداخلية المفوض:

بعد الإطلاع على الإعلان الدستوري الصادر في: 3 أغسطس 2011م.

وعلى الاتفاق السياسي الليبي الموقع بتاريخ: 17 ديسمبر 2015م.

وعلى القانون رقم ( 10 ) لسنة 1992 م، بشأن الأمن والشرطة.

وعلى القانون رقم (12) لسنة 2010 م، بشأن علاقات العمل ولائحته التنفيذية.

وعلى قرار مجلس الوزراء رقم ( 145 ) لسنة 2012 م، باعتماد الهيكل التنظيمي واختصاصات وزارة الداخلية وتنظيم جهاز الإداري.

وعلى قرار المجلس الرئاسي رقم ( 4 ) لسنة 2016 م، بشأن تشكيل حكومة الوفاق الوطني.

وعلى قرار المجلس الرئاسي رقم ( 12 ) لسنة 2016 م، بشأن منح تفويض بمهام.

وعلى قرار المجلس الرئاسي رقم ( 13 ) لسنة 2016 م، بشأن تشكيل لجنة وتحديدي مهامها.

وعلى قرار وزير الداخلية رقم ( 982 ) لسنة 2012 م، بشأن اعتماد التنظيم الداخلي لوزارة الداخلية.
