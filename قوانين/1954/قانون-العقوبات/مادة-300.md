مادة (300)

ظروف مشددة

تزاد العقوبات المقررة في المادتين (297) و (299) بمقدار لا يجاوز النصف إذا ارتكب الفعل على إحدى المباني أو المنشآت الآتية:

المبـاني العمومية أو المعدة للاستعمال العام أو للعبادة أو النصب التذكارية أو المقابر أو ملحقاتها أو الغابات أو الأحراش.

الأبنية المسكونة أو المعدة للسكنى أو المعامل أو ساحات العمل أو المحـاجر أو المناجم أو الترع أو منشآت توزيع المياه أو ما إلى ذلك مما يعد لجمع المياه، أو تصريفها.

السفن أو العائمات الأخرى أو الطائرات

محطات السكك الحديدية أو مواني السفن أو مهابط الطائرات أو المخازن العامة مستودعات البضائع أو الغلال أو أكـوام أو مستودعات المفرقعات أو المواد المحرقة أو الوقود.
