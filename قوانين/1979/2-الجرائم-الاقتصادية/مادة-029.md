مادة (29)

يعاقب بالسجن كل موظف عام طلب لنفسه أو لغيره أو قبل أو أخذ عطية أو وعدا بشيء لا حق له فيه نقداً كان أو أية فائـدة أخرى لاستعمـال نفوذ حقيقـي أو مزعوم للحصول أو محاولة الحصول من أية سلطة عامة أو أية جهة خاضعة لإشرافها على أعمال أو التزام أو مقاولة أو اتفاق توريد أو ترخيص أو أوامر أو قرارات أو أحكام أو وظيفة أو خدمة أو رتبة أو أوسمة أو أية مكافأة أو مزية من أي نوع.
