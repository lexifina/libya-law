# المادة 853 - القسمة النهائية بالمهايأة
1- للشركاء أن يتفقوا أثناء إجراءات القسمة النهائية ع لى أن يقسم المال الشائع مهايأة بينهم، وتظل هذه القسمة نافذة حتى تتم القسمة النهائية.
