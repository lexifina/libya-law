# المادة 502 - الحصة العينية
1. .إذا كانت حصة الشريك حق ملكية أو حق منفعة أو أي حق عيني آخر وجب تقويمها بالنقد يوم انعقاد الشركة، وتسري أحكام البيع في ضمان الحصة إذا هلكت أو استحقت أو ظهر فيها عيب أو نقص.
2. أما إذا كانت الحصة مجرد الانتفاع بالمال، أو أجرة عمل ثبتت له، فإن أحكام الإيجار هي التي تسري في كل ذلك.
