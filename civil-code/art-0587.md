# المادة 587 - ضمان الأجرة
يجب على كل من أستأجر منزلاً أو مخزناً أو حانوتاً أو مكاناً مماثلاً لذلك أو أرضاً زراعية أن يضع في العين المؤجرة أثاثاً أو بضائع أو محصولات أو مواشي أو أدوات تكون قيمتها كافية لضمان الأجرة، هذا مالم تكن الأجرة قد عجلت، ويعفى المستأجر من هذا الالتزام إذا تم الاتفاق على هذا الإعفاء أو إذا قدم المستأجر تأميناً آخر.
