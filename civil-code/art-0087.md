# المادة 87 - الأموال العامة
1- تعتبر أموالاً عامة، العقارات والمنقولات التي للدولة أو الأشخاص الاعتباري ين العامين والتي تكون مخصصة للمنفعة العامة بالفعل أو بمقتضى قانون أو قرار، من مجلس قيادة الثورة أو من مجلس الوزراء أو من الوزير المختص.
2- .وهذه الأموال لا يجوز التصرف فيها أو الحجز عليها أو تملكها بالتقادم
