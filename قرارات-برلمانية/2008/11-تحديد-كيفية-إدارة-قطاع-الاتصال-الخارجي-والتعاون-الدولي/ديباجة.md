قرار مؤتمر الشعب العام رقم ( 11 ) لسنة 1376 و.ر

بشأن تحديد كيفية إدارة قطاع الاتصال الخارجي والتعاون الدولي

وكيفية اختيار لجنته الشعبية

مؤتمر الشعب العام،

بعد الإطلاع على القانون رقم ( 1 ) لسنة 1375 و.ر بشأن نظام عمل المؤتمرات الشعبية واللجان الشعبية.

وعلى القانون رقم ( 2 ) لسنة 1369 و.ر بشأن تنظيم العمل السياسي والقنصلي ولائحته التنفيذية.

وعلى قرار مؤتمر الشعب العام رقم ( 5 ) لسنة 1375 و.ر، بشأن تحديد كيفية إدارة قطاع الاتصال الخارجي والتعاون الدولي واختيار لجنته الشعبية.

قــــــــــــــــرر

مادة (

1

)

يدار قطاع الاتصال الخارجي والتعاون الدولي بلجنة شعبية عامة على النحو الآتي:

1- أمين للجنة الشعبية العامة للاتصال الخارجي والتعاون الدولي.

2- أمين لشؤون الاتحاد الإفريقي.

3- أمين للشؤون العربية.

4- أمين للشؤون الآسيوية.

5- أمين للشؤون الأوروبية.

6- أمين لشؤون الأمريكتين.

7- أمين لشؤون الهجرة والمغتربين.

مادة (

2

)

يتم اختيار أمين اللجنة الشعبية العامة للاتصال الخارجي والتعاون الدولي من مؤتمر الشعب العام، وتتولى اللجنة الشعبية العامة تسمية أعضاء اللجنة الشعبية العامة للاتصال الخارجي والتعاون الدولي، وفقا لما ورد بالمادة الأولى من هذا القرار.

مادة (

3

)

يعمل بهذا القرار من تاريخ صدروه، وينشر في مدونة التشريعات.
